# Roadmap and acceptance criteria

Status: directional research agenda, 2026-11-23. Check the README for implementation truth.

## 1. Validate a bounded learning loop

Implemented: original pilot lessons, explicit concept graph, small tasks, assistance markers, profile evidence, visual manipulation, optional tutoring, speech affordances, persistent owner access, source register, private-library adapter, and restartable experimental roles.

Next acceptance: author matched transfer tasks and proof rubrics; independently review mathematical correctness; demonstrate delayed task scheduling in the UI; review proofs without silently converting unverified work into mastery; test fresh-session continuity from current structured state.

## 2. Build the literature and textbook review program

Expand beyond initial source screening into licensed full-text critical review. The library should deduplicate versions and store assets privately. Review chapters across all major mathematics fields and record hidden prerequisites, alternative sequences, and representations. Link architectural changes to section-specific evidence and counterevidence.

Acceptance: reproducible search logs, appraisal records, rights provenance, human-reviewed synthesis, and explicit changes to a release. A large metadata index alone does not satisfy this phase.

## 3. Improve the learner and simulation models

Compare trace memory, ACT-R task models, Bayesian knowledge tracing, cognitive diagnosis, and alternative latent-state models. Add semantic tasks, proof-strategy representation, chunk acquisition, misconceptions, interference, variable prior knowledge, and calibration against consented human traces.

Acceptance: held-out prediction/calibration checks, recoverable parameters, architecture sensitivity analysis, transfer tests, and no unsupported human-equivalence claim.

## 4. Expand problem and proof infrastructure

Add typed, mathematically checked generators, constraint-based variations, difficulty estimates, famous-problem context, counterexamples, proof planning, and optional Lean checking in an isolated runner. Preserve a held-out evaluation bank.

Acceptance: correctness audits across seeds, nontrivial transfer items, source rights tracked, malicious-code isolation, and clear separation of kernel checking, rubric review, and learner understanding.

## 5. Expand visual narratives

The initial SVG scenes cover a small allowlist. Evaluate Manim for rendered clips, Motion Canvas for narrated vector sequences, and Penrose for declarative diagrams. Design a domain-specific scene specification before allowing arbitrary output.

Acceptance: semantic checks, bounded rendering, original assets, textual alternatives, reduced motion, narrative review, cache/reuse, and observed learning benefit beyond visual appeal.

## 6. Run human studies and evolve the curriculum

Test objective-matched alternative pathways with preregistered outcomes and independent scoring. Introduce longitudinal and adaptive policy studies after the bounded pilot is credible. Only promote claims supported by the population and conditions studied.

## 7. From foundations to current research

Broaden authored and reviewed coverage progressively. Frontier paths must point to dated papers and distinguish established knowledge, preprint claims, open questions, and proofs awaiting verification. Use expert review and paper-specific prerequisite maps. The field cannot be represented as a permanently finished tree.

## 8. Additional domains

Add content packs with their own goals, representations, task validators, and review expertise. Preserve the shared infrastructure without assuming the epistemology or assessment methods of mathematics transfer unchanged to other subjects.
