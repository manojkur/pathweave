# Contributing

Start with a bounded issue: an original lesson, a source appraisal, a checked problem family, an accessibility improvement, or a reproducible experiment. Include assumptions and what would falsify the claimed improvement.

For a source, record the canonical identifier, exact inspected scope, population and outcomes where applicable, limits, and rights. Do not upload PDFs, commercial book scans, instructor-only materials, or private learner records. For a lesson, connect motivation, examples, formal definitions, a justified argument, a counterexample, and a transfer opportunity.

For code, run lint and relevant tests. Changes to authentication, persistence, scoring, budgets, and release publication need meaningful regression tests. Ordinary UI copy does not need tests that merely repeat its wording. Model output is untrusted input; do not execute generated code in the web or worker process.

Make claims proportionate to evidence. A synthetic result, a model score, a usability observation, and a causal human-learning result are different forms of evidence.
